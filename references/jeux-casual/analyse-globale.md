### Wordscapes — ce qu'il fait exactement
- **Word search + anagramme + crossword** fusionnés : trouver des mots cachés dans une roue de
  lettres pour remplir une grille façon mots croisés. Décors nature (relaxation).
- Sorti 2017, mis à jour 2026-08 (très actif). Note 4.83. 8 langues. 650K dl/mois.
- Monétisation : **ads abondantes + IAP ad-free + coins** (hints ~100 coins), tournaments
  week-end, daily puzzles, "piggy bank" (racheter ses coins gagnés !).

### NYT Games — ce qu'il fait exactement
- Suite de jeux : **Wordle, Crossword, Mini, Spelling Bee, Connections, Sudoku, Tiles, Pipsqueak**.
- Sorti 2009, mis à jour 2026-08. Note 4.80. 1 langue (EN) — c'est un produit US-first.
- Monétisation : **abo NYT Games** (inclut archive + tous les jeux) + IAP. $6M/mois.

### Voix des utilisateurs — Wordscapes (ce qui fait rêver)
1. **Jeu de "kill time" parfait** : pas de timer, on reprend où on s'est arrêté.
2. **Relaxation + stimulation cérébrale** : "escape from doomscrolling", "uses my brain".
3. Tournaments week-end + daily puzzles = rétention (récompenses, pfp, pet system).
4. Hints disponibles (contre coins) → la monétisation par friction douce fonctionne.

### Voix des utilisateurs — Wordscapes (plaintes = opportunités)
1. **"So many ads"** — plainte #1, même APRÈS achat ad-free (ads pour récompenses persistantes).
2. **Coins/hints trop chers** : "one hint per set", "hints cost an unholy amount of coins".
3. **Piggy bank = avarice perçue** : "I have to pay money to get the coins I earned" — la pire
   pratique (les utilisateurs la détestent, c'est un piège à éviter ABSOLUMENT).
4. **Vocabulaire répétitif** : "same words over and over", favoritisme de certains mots.
5. **Dictionnaire incomplet** : "a retired English teacher told me my word doesn't exist" (nerd !).
6. Coin system devenu payant (avant : coins gratuits utiles).

### Voix des utilisateurs — NYT Games (ce qui fait rêver)
1. **Qualité éditoriale des puzzles** = le moat absolu (crossword légendaire).
2. **Archive complète** : "the archive alone keeps me occupied for several years".
3. **Gold star daily completion** : mécanique addictive "kept me completing puzzles for 2 months".
4. **Party mode / AirPlay** : jouer en famille sur TV.
5. Les jeux sont joués avec famille/partenaire ("solve it every evening with my partner").

### Voix des utilisateurs — NYT Games (plaintes = opportunités)
1. **Abo pas transparent** : "no amount mentioned to download", "subscription terms are a
   bold-faced lie" (le sub in-app ne sync pas vers le web). → LA faille réputationnelle.
2. **Vertex absent de l'app** (obligé d'aller sur le navigateur).
3. **UI/UX de Pipsqueak cassé** (drag depuis le bas de l'écran = geste iOS conflictuel).
4. **Pas de leaderboard/friends que pour le Mini** ; pas de stats sociales sur Wordle.
5. **Bugs** : glitch party mode, sync lente entre devices, Bee ne reset pas.
6. **Nouvelle UI** : "shiny toy, ignores end user", features retirées.

### Synthèse monétisation
- **Wordscapes** : Ads + IAP (ad-free + coins/hints). **$1M/mois** — la pub + micro-IAP marche à
  grande échelle sur un casual à forte rétention.
- **NYT Games** : Subs (+IAP). **$6M/mois** avec 510K dl = **$11.7/download** — le modèle
  abonnement contenu premium est LE plus lucratif du casual.
- Gap : NYT est US-only (1 langue) et paywall agressif → un "word games" premium multi-langues
  (EN+ES+FR+DE) avec abo abordable peut prendre les non-anglophones.

### Stack RN + difficulté
- **Wordscapes-like** : RN + générateur de grilles/mots (dictionnaire) + animations (Skia).
  Complexité **2.5/5**. Le coût = dictionnaire de qualité + génération de niveaux non répétitive.
- **NYT-like (suite de mini-jeux)** : RN pur. Complexité **2/5** par jeu. Le coût = contenu
  éditorial quotidien (crossword/sudoku/wordle générés par IA ou template).

### Ce qu'il faudrait faire (sous-niche précise recommandée)
1. **"Word search for adults" premium ad-free** : le mot-clé est battable (51/55) et les plaintes
   Wordscapes (ads, piggy bank, vocab répétitif) décrivent exactement ce qu'il ne faut PAS faire.
   Proposer : dictionnaire riche, zéro piggy bank, abo léger $2.99/mois ou lifetime.
2. **Suite de word games multi-langues** : copier la structure NYT (daily puzzle + archive +
   stats) mais en **ES/FR/DE** où NYT est absent, avec **transparence d'abonnement** (le point
   que les utilisateurs reprochent à NYT).
3. **Word games "family/social"** : leaderboard friends multi-jeux (demande explicite dans les
   avis NYT), party mode.

### Verdict
- **Note : 7.5/10** pour le segment "word games" — monétisation PROUVÉE à deux échelles
  ($1M pub/IAP et $6M sub), mécaniques RN simples, demande forte (`word games 62/59`).
- **Attention** : Wordscapes (PeopleFun) et NYT sont des machines à contenu. L'angle gagnant est
  la **qualité anti-avarice** (pas de piggy bank, abo transparent, dictionnaire riche) +
  **multi-langues** (NYT est mono-EN).
- Le modèle "daily puzzle + abo" (NYT) est plus rentable par download ($11.7) que le modèle pub
  (Wordscapes $1.5) → privilégier l'abo si on vise la qualité, la pub si on vise le volume.
