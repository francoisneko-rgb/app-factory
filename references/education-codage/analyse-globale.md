### Tynker — ce qu'il fait exactement
- **"THE #1 CODING & AI APP FOR KIDS"** : 100M+ children, 150K+ schools. Blocs → Python → AI. Curriculum par âge, projets, communauté de publication.
- **Promesses ASO** : "Empower your child's future", "world's most advanced coding platform", "learning to code an adventure".
- Note 4.58 (18 317 avis), sorti 2014. Freemium → abo. **$25K/mois, 5K dl = $5/download.**

### codeSpark — ce qu'il fait exactement
- **"The Award-Winning Learn-to-Code App for Kids (Ages 3-10)"** : puzzles, création de jeux/histoires, "Made by Kids" (jeux d'autres enfants), contests mensuels, multiplayer (Splash Clash), 5 profils enfants (abo annuel).
- **Curriculum basé sur la recherche MIT, Princeton, Carnegie Mellon**. "without words" (pré-lecteurs).
- Note 4.57 (40 523 avis), sorti 2014, dev = Homer (Byju's). Freemium (Hour of Code gratuit) → abo mensuel/annuel (7-day trial).
- **$120K/mois, 10K dl = $12/download** (le plus rentable du cluster).

### Voix des utilisateurs — Tynker (ce qui fait rêver)
1. **Créativité + communauté** : "I love this game, I can make cool animations, and post projects" — les enfants créent et partagent.
2. **Vocation** : "This app inspires me to my dreams, which makes me want to be a software developer".
3. **Attachement émotionnel fort** : un avis 5★ raconte une amitié créée via le partage de projets (communauté = valeur émotionnelle).
4. **Simple pour les enfants** : les blocks par glisser-déposer accessibles.

### Voix des utilisateurs — Tynker (plaintes = opportunités)
1. **PRIX (la plainte #1)** : "You have to get at least a $25 subscription to even USE the app", "Prices are too expensive for an app", "about every two minutes, you would be asked to get a more expensive subscription" — **paywall agressif = 1★.**
2. **Modération/review des projets** : "my projects are now taking forever to be reviewed... MONTHS", "Tynker declines projects for no reason".
3. **Communauté toxique** : "Tynker has a community where you can publish your projects, but Tynkerers are being really toxic and starting drama".
4. **Bugs éditeur de texte** : "the 'say message' block was working perfectly... now it's acting up constantly".

### Voix des utilisateurs — codeSpark (ce qui fait rêver)
1. **"My kids LOVE it so much!"** : les enfants jouent seuls, ensemble, ou en vidéo avec des amis (partage d'écran).
2. **Création de jeux/histoires** : "I adore creating stories, and playing other coders games".
3. **"Not REAL coding"... mais les enfants apprennent** : les parents doutent, les enfants insistent ("my parents say it's not REAL coding, but I disagree") — la perception "jeu vs éducation" est un point de friction marketing.
4. **Service client top** : "Sandra went through 1,000s of emails and found that I had unknowingly created..." (5★ pour le support).

### Voix des utilisateurs — codeSpark (plaintes = opportunités)
1. **ABO OBLIGATOIRE (la plainte #1)** : "I downloaded it and apparently you must pay monthly for this... I'm only 14 and can't do monthly payments" (2★) — pas de vrai free.
2. **Glitches (Splash Clash float glitch)** : bugs multi-joueurs.
3. **Modération des partages** : "it got reported! It said 'there was something illegal in the story' but it was called 'time: the movie'" — faux positifs de modération.
4. **Pas de communication entre enfants** : "I do wish you could communicate with other coders" (mais sécurité = pourquoi ils ne le font pas).

### Synthèse monétisation
- **Tynker** : abo. $25K/mois. Paywall agressif = la plainte #1.
- **codeSpark** : abo (7-day trial, 5 profils). $120K/mois, $12/download. Le modèle "famille multi-enfants" monétise mieux.
- **Les deux** : marché **modeste** (25-120K/mois vs 220K-3M pour education-kids). Les parents paient moins pour le codage que pour la lecture/maths.

### Stack RN + difficulté
- **Editeur de blocs visuel (scratch-like)** : RN + composant custom (déjà fait par Scratch/Blockly en JS). Complexité **2-3/5** (l'éditeur de blocs est le coeur technique).
- Contenu pédagogique (leçons, progression) à produire.

### Ce qu'il faudrait faire (sous-niche précise recommandée)
1. **Mini-jeu de codage ciblé (la pépite)** : PAS un concurrent complet de Tynker/codeSpark, mais **UN jeu de logique/sequencing pour UN âge** (ex. "coding game for 5-7" : un puzzle game où on ordonne des actions pour aider un personnage).
2. **Corriger les plaintes** :
   - **Free play GÉNÉREUX** (les 2 plaintes #1 = paywall) : premier monde gratuit complet, pas "Hour of Code" à la codeSpark.
   - **Modération transparente** (faux positifs Tynker/codeSpark) : review des créations en <24h ou auto-publié avec signalement.
   - **Zéro pub** (standard du cluster).
3. **Monétisation** : abo familial $4.99-6.99/mois (sous-coté vs Tynker $25) ou **IAP one-shot** pour débloquer les mondes suivants — le marché n'aime pas l'abo obligatoire (plaintes des 2 apps).
4. **Angle différenciant** : "coding for kids WITHOUT screens of text" — l'approche codeSpark (wordless) est validée par la recherche MIT/Princeton. Un puzzle game wordless et beau peut battre les deux sur la niche 3-6 ans.
5. **Vérifier la demande** : `coding for kids`, `learn programming`, `scratch` sur Appfigures avant de valider.

### Verdict
- **Tynker : $25K/mois, paywall agressif = vulnérable sur le free-to-play.**
- **codeSpark : $120K/mois, $12/dl — le modèle "family multi-profile" est le plus rentable.**
- **Note révisée : 5/10 maintenue** — marché modeste vs education-kids (220K-3M), mais les plaintes paywall des 2 leaders ouvrent une porte : **un coding puzzle game wordless, gratuit au début, à abo doux**. Stack faisable en RN (éditeur de blocs en JS).
