## Forces / Faiblesses
- **Forces** : officielle, obligatoire, volume massif (710K dl/mois), tout-en-un (qibla/Quran/prayer/visa).
- **Faiblesses** : update quotidienne forcée, réservation Rawdah cassée, login/support catastrophiques, features retirées, énorme (742 MB), sentiment récent désastreux (17 %).

## Réutilisable pour nous
- **Nusuk est UNE app d'État : on ne la bat PAS frontalement** (obligatoire pour le pèlerinage). MAIS elle **laisse des gaps** :
  1. **Fiabilité** : stable, pas d'update forcée, offline.
  2. **Rawdah/permis** : pas de "register interest + alert" (demande explicite : "simple register interest feature with automatic alerts").
  3. **Duas/adhkar/prayer countdown REMIS** : les users réclament ces fonctions retirées par Nusuk → **complément athkar/duas** (cross avec notre cluster islam-athkar).
  4. **Léger** : Nusuk = 742 MB, une app tierce légère (30 MB) offline est différenciante.
  5. **Support** : guides clairs et précis (plainte "no clear step-by-step for Rawdah visit").
