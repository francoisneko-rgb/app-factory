## 3. Description des leaders

- **SnoreLab** : enregistre/analyse le ronflement.

## 5. Monétisation
- **Abonnement** (Sleep Cycle, BetterSleep, SnoreLab = Subs).
- Le contenu audio (sons) est réutilisable.

## 6. Stack & difficulté
- **Stack RN** : RN + audio + (option) micro (analyse son). Complexité 2-3/5.
- Difficulté : apps de sons faciles à copier ; l'analyse son = natif.

## 7. Ce qu'il faudrait faire (si on choisit)
1. Choisir UNE sous-niche : décibel mètre (outil précis), bruit blanc pour bébé, brown noise.
2. Contenu audio + UI simple.
3. Monétisation abo léger ou IAP.
4. **Angle** : outil utilitaire précis (décibel) plutôt que "une app de sons de plus".

## 8. Verdict
- **Note : 6/10** : monétisation prouvée (Sleep Cycle $740K), mais beaucoup d'apps de sons
  et commodité.
- **Pépite** : décibel mètre (36-45/48-56) — utilitaire précis, peu de bons produits.

- **Analyse du sommeil par micro** (patented sound technology) + **Smart Alarm** qui réveille en
  phase légère + **AI sleep coach "Luma"** + détection ronflement/toux/parle + sons/musique/stories.
- "World's no.1 sleep app, 40M downloads", 3M users. Récompenses (Gold Mobile Digital Health 2024).
- Note 4.68 (28K avis). MAJ 2026-08-24, version 6.26.32, iOS 16.2+, **455 MB** (très lourd).
- **Promesses ASO** : "built on science", "no.1 sleep app", "40 million downloads", "patented",
  "AI sleep coach", awards.

### BetterSleep — ce qu'il fait exactement
- **Mixeur de sons personnalisable** (bruit blanc, pluie, brown noise, feu, oiseaux...) + sleep
  tracker + sleep recorder + méditations + stories + hypnose + breathwork.
- "App of the Day" 65+ fois, "most positively reviewed app in history" (Business Insider), "91% slept better in 1 week".
- Note 4.74 (390K avis). MAJ 2026-08-24, version 26.15, iOS 15+, 303 MB. 10 langues.
- **Promesses ASO** : "91% slept better", "App of the Day 65 times", "most positively reviewed app",
  "leading doctors recommend" — preuve sociale massive dans le titre.

### Voix des utilisateurs — Sleep Cycle (forces)
1. **"The wake-up window is a game changer"** : se réveiller en sommeil léger, sans groggy.
2. **Enregistrements nocturnes** (ronflement, toux, sommeil) revus le matin — insight unique.
3. **Corrélations** : notes libres ("took melatonin") + météo → comprendre ce qui aide.
4. "Brought my average sleep from 6.5h to 7.4h" — résultat concret.

### Voix des utilisateurs — Sleep Cycle (plaintes = opportunités)
1. **"This app lost a 5+ year customer"** : achat **lifetime** autrefois → aujourd'hui **abo forcé**,
   "every update has increased how bloated it is", alarme qui parle toute seule.
2. **"Shady" business model** : "I paid for early adopter lifetime access... it is bogus".
3. **"Money Hungry!"** : tout est derrière un paywall ("insights now premium feature").
4. **Graphique sur-lissé** (update 6.25.9) : "substantially overprocesses the sleep graph" —
   les utilisateurs avancés veulent les **données brutes**.
5. **Pas de contrôle des notes** : "you name a note once and you can never change it, no folders".
6. **Prix annuel** : "not everyone can afford annual fees, we need monthly".

### Voix des utilisateurs — BetterSleep (forces)
1. **Le mixeur de sons = culte** : "I like layering water sounds, brown noise, and a little quiet thunder.
   It's created an almost Pavlovian response; I start my mix and next thing I know, I'm asleep."
2. **"This app saved my life"** : insomnie, deuil, anxiété — les transformations émotionnelles.
3. **Hypnose du sommeil** utilisée toutes les nuits.
4. **Cohérence sur 10+ ans** : "year after year, it's always improving".
5. Réactivité du support dev ("got the developer to respond, rated 5 stars now").

### Voix des utilisateurs — BetterSleep (plaintes)
1. **Contenu premium verrouillé** : "you miss out on a lot of stories/meditations if you don't buy".
2. Musique externe : "it now just uses outside apps instead to help with sounds" (lecture musique moins intégrée).
3. Hypnose migraine : la narration d'une méditation spécifique ne convient pas (détail).

### Synthèse monétisation
- **100 % Sub** : Sleep Cycle $740K/mois (190K dl = **$3.9/download**) ; BetterSleep $770K/mois (140K dl = **$5.5/dl**).
- **BetterSleep monétise mieux par download que Sleep Cycle** (contenu audio vs outil).
- Anti-pattern partagé : **passage forcé de lifetime → abo** = colère des anciens utilisateurs
  → opportunité pour un modèle **lifetime honnête** ou **abo mensuel** (plaintes explicites).
- L'audio réutilisable (mêmes sons vendus depuis 15 ans) = marge énorme une fois le contenu produit.

### Stack RN + difficulté
- **Sleep Cycle-like** : RN + **module natif audio/micro** (analyse du sommeil, détection sons) +
  graphiques + alarme système. Complexité **3/5** — le vrai mur est l'**algorithme d'analyse du sommeil**
  (brevets Sleep Cycle) et l'intégration alarme fiable en iOS.
- **BetterSleep-like** : RN + lecteur audio (mixage multi-pistes) + sleep tracker simple.
  Complexité **2/5**. Le mur = le **catalogue audio** (centaines de sons/stories/méditations à produire ou licencier).
- À noter : 455 MB (Sleep Cycle) et 303 MB (BetterSleep) = apps très lourdes → un concurrent
  **léger et rapide** peut se différencier.

### Ce qu'il faudrait faire (sous-niche précise recommandée)
1. **NE PAS refaire un "sleep tracker général"** — Sleep Cycle est breveté et leader ; NE PAS
   refaire un "mixeur de sons général" — BetterSleep a 15 ans de catalogue.
2. **GAP #1 — "No-nagging / lifetime honest"** : la colère anti-abo est explicite et massive
   ("lost a 5+ year customer", "shady", "money hungry") → une app de sons de sommeil avec
   **prix unique raisonnable ou abo mensuel transparent** (pas annuel forcé). Angle :
   "one-time purchase, no subscription". Public : les 40+ qui ont vécu le lifetime → abo.
3. **GAP #2 — Données brutes** : "the new graph overprocesses my data" → un sleep tracker
   **orienté données brutes** (graph non lissé, exports CSV) pour les utilisateurs avancés /
   insomniaques qui veulent comprendre. Exactement le public que Sleep Cycle délaisse.
4. **GAP #3 — Sons de niche ciblés** : les pépites CSV (`brown noise`, `white noise for sleep`,
   décibel mètre) → une app **ultra-focus** (ex. brown/green noise 1$ lifetime) avec 10 sons de
   qualité > 500 sons médiocres. Les géants sont devenus des usines à contenu ; la **simplicité
   ciblée** est la faille.
5. **Décibel mètre (36-45/48-56)** : utilitaire précis, aucun géant, peu de bons produits → toujours valable.

### Verdict
- **Sleep Cycle / BetterSleep : 7/10 pour le marché** — $1.5M/mois combinés après 15+ ans,
  monétisation $4-5.5/dl, marché durable. Mais **méfiance croissante des utilisateurs** (abo forcé).
- **Notre entrée : 6/10** — le créneau "sons de sommeil à prix unique / données brutes" répond à
  des plaintes explicites. Stack 2-3/5, pas de licence bloquante, mais il faut produire un
  catalogue audio décent et l'analyse sommeil de qualité demande du travail natif.
  **L'angle "honnête" (pas de piège d'abonnement) est le différenciateur le plus crédible.**
