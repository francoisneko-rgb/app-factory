# ANALYSE — FITNESS / WORKOUT PLANNER (2026-08-30)

## 1. Ce que c'est
Apps de planification et suivi d'entraînement : plans de séances, logs de séries/reps/poids,
progression, programmes, (option) vidéos. Marché MASSIF et très monétisé.

## 3. Description des apps leaders (ce qu'elles font)
- **Hevy** : tracker d'entraînement poids "le plus intuitif", sans pub, gratuit + pro. Log de
  séries, routine, progression, communauté. ("Weight Lifting Routine Planner")
- **Fitbod** : plan d'entraînement personnalisé généré selon tes équipements/objectifs, adapté à
  chaque séance. Apple Editor's Choice.
- **Strong** : tracker d'exercices le plus simple, historique, routines.
- **MyFitnessPal** : suivi nutrition + fitness tout-en-un (gratuit + abo).

## 4. Les mots-clés battables (longue traîne, pour un indie)
- `workout planner (52/58)`, `workout app free (50/48)`, `weight tracker (48/36)`,
  `workout: planner (53/40)`, `exercise tracker (32/59)`
- **Cross-niches sous-exploitées** (mais petit volume) : workout + femmes (34/53),
  workout + seniors (chair yoga 30/59), workout + réhab (medbridge go 51/58).

## 5. Monétisation
- **Abonnement** dominant (Subs) : $9.99-19.99/mois ou annuel.
- Hevy/Strong : freemium + IAP (pro one-time ou abo).
- **L'opportunité indie** : un workout tracker de NICHE (ADHD, réhab, femmes, seniors, poids
  de corps) plutôt qu'affronter Hevy/Fitbod sur le général.

## 6. Stack & difficulté
- **Stack RN** : RN + HealthKit + (option) vidéos. Complexité 2-3/5.
- **Difficulté réelle** : ce n'est pas la technique mais la QUALITÉ (Hevy noté 4.90 = barre très
  haute) et le volume de contenu.

## 7. Ce qu'il faudrait faire (si on choisit)
1. Choisir UNE sous-niche précise (ex. "workout tracker pour poids de corps / home workout",
   "workout tracker pour femmes", "workout + ADHD").
2. Produit simple mais impeccable (log rapide, progression, widgets).
3. Monétisation abo $4.99-9.99/mois ou lifetime.
4. ASO sur la longue traîne (workout planner, weight tracker).

## 8. Verdict
- **Note : 7.5/10** (demande massive + monétisation prouvée) MAIS **géants très forts**.
- À faire UNIQUEMENT avec un angle de niche précis, pas en frontal contre Hevy/Fitbod.
- Stack RN parfaitement adapté.

## 9. ANALYSE APPROFONDIE (2026-08-30) — HEVY (la référence à copier)

### Hevy — ce qu'il fait exactement
- **Tracker d'entraînement poids** : log de séries/reps/poids, routines, historique, graphiques
  de progression, communauté, exercices avec démo de forme, Apple Watch (complications + input
  poids/reps sur la montre), création d'exercices personnalisés.
- **Modèle** : gratuit + Pro. **Lifetime disponible** (très apprécié — "PLEASE don't remove this
  option, its value is unbelievable") + abo ~$2-6/mois.

### Ce que les avis disent (points forts à copier)
1. **Simplicité + UI propre** (cité partout : "simple UI", "easy to use").
2. **Lifetime purchase** = différenciateur ÉNORME vs abonnements forcés.
3. **Apple Watch** (complications, input sur montre) = très demandé.
4. **Démo de forme des exercices** (beginner friendly) + création d'exercices custom.
5. **Label drop sets / failure sets / supersets** — les apps sérieuses le veulent.
6. **Sync iPhone/iPad + communauté** (engagement).
7. **Prix bas** ($2/mois) = accessible.

### Les plaintes / opportunités (ce que les concurrents ratent)
- "Others could easily catch up" → le marché n'est pas fermé si on est meilleur sur UN point.
- Manque cité (senior user) : certaines fonctionnalités avancées.
- → **Angle gagnant** : un workout tracker SIMPLE + lifetime + watch, mais ciblé sur UNE
  sous-niche (femmes, seniors, poids de corps, réhab) plutôt qu'affronter Hevy sur le général.
