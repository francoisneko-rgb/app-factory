## 1. Ce que les captures couvrent — et ne couvrent pas

Couverture quasi complète du funnel **avant dashboard** : swiper marketing (4 écrans), questions
personnalisées (5), sélection de challenge (6+), détail de challenge, validation, création de
compte, **matching de partenaire (3 écrans)**, invitations (1), partage social (1), récap (1),
paywall (1), porte de notation (1). Captures 21-27-30 → 21-27-40 sont une **2ᵉ passe
documentaire** (mêmes écrans re-parcourus : 21-24-39 ≈ 21-27-30, 21-24-43 ≈ 21-27-35, nom ≈ 21-27-40).

Non couvert : dashboard quotidien, tracking jour/jour, écrans internes après « Start now ».
**[hypothèse]** Le paywall (21-29-42) ouvre sur le dashboard non capturé ; la porte de notation
(21-28-40) peut se situer après un moment de valeur réussi, position exacte incertaine.

## 4. Architecture de l'information

- Funnel onboarding **linéaire non-tab** jusqu'au dashboard ; pas d'union visible avant « Start now ».
- Détail défi non corrus : une seule chose par écran (liste, post-its, avis) découpés en
  plusieurs captures [hypothèse : un seul écran scrollable].
- IA interne (tabs home, tracking) : **non perceptible** dans ces captures. [hypothèse : 3 tabs
  (Ma journée / Ma clique (community) / Profil) — extra-pattern courant, non démontré.]
- Compteurs sociaux croisés : +8 672 (E1) vs +20 000 (carte défi) vs +200,002 (paywall) vs
  24,000+ (match) — chiffres non cohérents entre eux [hypothèse : compteurs vivants + diverses
  unités (joined du défi vs joined de l'app vs women matchées).]

## 5. Choix UX notables

1. **« Value before bed »** : les questionnaires algorithment l'IHM avant le compte ; Google
   auth demandé APRES la validation du défi (contraste direct avec BeHard).
2. **Matching de partenaire (dating app appliqué au fitness)** avec % match, statut live,
   personnalité en bulles pastel = différenciation émotionnelle forte ; sortie solo visible.
3. **Stat morales chiffrées** (« 87% ... with them », « +30% success with friends ») qui vendent le
   social AVANT de le proposer.
4. **Farewell/ite à régénérer l'app Génère sticker story partageable** (« Make it official »):
   le démarrage du défi devient du contenu, et la distribution est gratuite.
5. **Badge avec invitation code stocké dans une carte texture papier**, CTA désiré noir, alternative
   « solo » grise — nudging franc mais pas fermé.
6. **Paywall tardif** : uniquement après la co-création ; avant de payer, l'utilisateur a une
   « carte day one » personnalisée en main.
7. **Defaults inversés** : présélection Monthly (hors ancre) — la version Longue Durée y est
   seulement un badge « Save 72% » px ; choice-architecture qui donne le moyen terme à vendre.
8. **Tout est comestible avec des photos réelles** (fleurs, marée, livres, matcha) vs « cut-outs »
   produits — la palette parle « vibe lifestyle », pas « fitness militaire ».

## 6. Qualité perçue : **9/10**

- **+** : continuité de ton totale (identité, copywriting, visuels, social) ; funnel narrativeuk
  (choix → co-création → appartenance → réputation) ; viralité par invite code + sticker ;
  matching = mécanique de rétention différée ; paywall nourri de preuves et positions.
- **−** : pricing mensuel à 14,99 € en présélection (choix arbitraire qui brûle de la confiance) ;
  contradiction des compteurs (8 672 vs 200,002) ; typo « Privacy police » ; aucun dashboard
  capturé (coquery d'usage quotidien non verificable ici).

## 8. À retenir pour la suite du travail

- Le couple **copywriting social-chiffré (87% / +30%) + matching partenaire** est le motif le plus
  défendable de l'app. Le **sticker story** est le quiiter viral de la catégorie.
- Les compteurs sociaux présents partout, même dans l'onboarding, font masse au store.
