## 6. Stack & difficulté
- **Stack RN** : pur RN (quiz, flashcards, progression). Complexité 1/5.
- **Difficulté** : le contenu officiel (questions de code) = il faut la licence/les données
  (DVSA au UK, etc.) — c'est LE point bloquant.

## 7. Ce qu'il faudrait faire (si on choisit)
1. Choisir un pays/marché (US permit test, UK theory test).
2. Obtenir/constituer la base de questions (ou utiliser des données open source).
3. App de quiz simple + bien notée.
4. Monétisation IAP (pack de tests) ou abo.
5. **Angle IA** : un "AI math/quiz helper" pour élèves (Photomath-like mais de niche) est le
   créneau le plus porteur (demande 53-57, marché en croissance).

## 8. Verdict
- **Note : 7/10** pour le "theory test" classique (demande 67, comp battable, stack simple)
  MAIS contenu officiel requis.
- **Note : 6.5/10** pour "IA math/aide devoirs" (demande réelle, monétisation prouvée $160-350K,
  mais Photomath/Brainly = gros concurrents).

- **Scan caméra d'un problème de maths → solution pas-à-pas** (arithmétique → calcul).

### Voix des utilisateurs — Driving Theory Test (ce qui fait rêver)
1. **"Passed first time"** répété partout — la promesse fonctionne, l'app tient parole.
2. Question bank + explications = méthode "active recall" appréciée (feedback immédiat, barre pass/fail).
3. **Flagged questions + répétition des erreurs** = "helped me pass", "keeps track of failed questions".
4. Hazard perception clips à $1.99 = IAP one-shot qui convertit.
5. Sync + offline + US store available (les expats américains l'utilisent !).

### Voix des utilisateurs — Photomath (plaintes = opportunités)
1. **PAYWALL trop agressif** : "used to be free, now $10/month", "pay to see steps" —
   la plainte #1. Les steps de base sont limités à 1-2 puis paywall.
2. **Prix perçu trop élevé** : "$10 a month will start adding up, most people don't have money for it".
   → Opportunité : un solver IA à prix cassé ou freemium généreux sur les steps.
3. **Dépendance au scan** : si la caméra casse, plus d'app ("my camera broke, I can't use it anymore")
   → opportunité : input clavier/photo/texte + IA conversationnelle.
4. **Bug scan** : "keeps saying adjust the frame for an hour", lags sur nouveaux iPhones.
5. **Demande claire** : "a learn option that teaches you by solving problems + quizzes" (mode
   pratique, pas juste la réponse).
