### Bookmory — ce qu'il fait exactement
- **Le tracker de lecture complet** : ajout de livres (recherche + **scan code-barres**), timer de lecture intégré, goals quotidiens/annuels, **calendrier visuel** (covers sur les dates), stats annuelles (Annual Rewind), journal de lecture avec notes + citations + **OCR** (extraire du texte de photos), collections/tags/séries, thèmes, app lock, iCloud backup.
- **Promesses ASO** : "Build a lasting reading habit", "you don't just track it — you remember it forever", "beautiful reading statistics", "reading streak".
- Dev **solo** (TonySoft), note 4.84 (16 085 avis), sorti 2020, très actif (v1.4.17, mis à jour 2026-08-27).
- **$65K/mois avec 65K dl = $1/download**, monétisation mixte : abo Premium + ads à regarder pour les stats.

### Voix des utilisateurs — Bookmory (ce qui fait rêver)
1. **LE CALENDRIER (la feature signature)** : "I saw someone using the calendar feature from this app on social media and immediately downloaded it" — **le calendrier viralise sur les réseaux sociaux** (c'est le moteur de croissance). "It's fun to look and see pictures of the books I've read".
2. **Timer + précision** : "you can see exactly how long it took you to read a book (ex: Hunger Games took me 4 hours and 53 minutes)".
3. **Statut "gave up"** : "what I like about this one is the option of choosing 'gave up' for a book" — différentiation vs Goodreads/StoryGraph.
4. **"11/10 recommended"** : "out of all of the books apps i've used (storygraph and goodreads), this is the best one" — Bookmory dépasse les géants pour le tracking pur.
5. **"Switching over!"** : les utilisateurs MIGRENT depuis Leio, Bookly, StoryGraph → marché de migration actif.

### Voix des utilisateurs — Bookmory (plaintes = opportunités)
1. **PAYWALL + ADS (la plainte #1)** : "without the subscription the app is borderline unusable", "it dangles those fun stats in front of you that you can't really look at unless you watch an ad or pay" (3★) — **les stats (le coeur de la valeur) sont derrière pub/abo**. Une migrante Bookly (500 livres) est partie à cause de ça.
2. **Pas de réorganisation des livres** : "I really wish they would add a feature where you can reorganize books from the order they were added in" (3★).
3. **Pas d'import** : "I wish there was a way to import my reading data from my other reading tracker" — besoin de migration (Goodreads CSV, Bookly...).
4. **Crashs** : "I ended up buying the subscription because the app kept crashing" (acheté pour le support).

### Synthèse monétisation
- **$65K/mois, $1/download** — le plus accessible des clusters analysés (dev solo, stack RN pur).
- Modèle : abo Premium (ads-off + sync + backup) + ads de secours. Les lecteurs sont prêts à payer pour l'habitude ("support and subscribe for a year").

### Stack RN + difficulté
- **RN pur** : listes, timer, stats, calendrier, OCR (module natif VisionKit), scan code-barres. Complexité **2/5**.
- Pas d'API externe nécessaire (recherche de livres via Google Books/iTunes API gratuites).

### Ce qu'il faudrait faire (sous-niche précise recommandée)
1. **Book tracker "2.0" qui corrige Bookmory** :
   - **Stats GRATUITES** (la plainte #1 : les stats derrière pub/abo = le coeur frustrant). Le calendrier viral doit être gratuit → croissance organique via partages sociaux.
   - **Import Goodreads/Bookly CSV** (la 2e plainte : les migrants Bookly/Leio/Goodreads cherchent un foyer — Bookmory les prend déjà, on peut les prendre à Bookmory).
   - **Réorganisation libre des listes** (3e plainte).
   - **Backup iCloud gratuit** (leçon Fuel Record : ne jamais faire payer le backup).
2. **L'angle** : "le calendrier de lecture partageable + import Goodreads" — le calendrier est LA feature virale prouvée (découverte via réseaux sociaux). Un partage encore plus beau (cartes animées, stats hebdo) = boucle virale.
3. **Monétisation** : abo doux ($2.99/mois ou $19.99/an) pour le confort (thèmes, sync multi-device, stats avancées), MAIS le core (calendrier + stats de base) gratuit. Les lecteurs ont déjà prouvé qu'ils paient (Bookmory $65K).
4. **Vérifier la demande** : `book tracker`, `reading tracker`, `bookmory (46/68)` sur Appfigures.

### Verdict
- **Bookmory : $65K/mois dev solo = preuve que le créneau est rentable et battable.** Ses plaintes (paywall stats, pas d'import, pas de réorganisation) sont des gaps précis et corrigeables.
- **Note révisée : 6/10** (au lieu de 5.5) : la preuve solo + la viralité du calendrier + les plaintes identifiées = **la sous-niche la plus faisable du portefeuille avec un dev solo**.
- **Recommandation : book tracker avec calendrier viral gratuit + import Goodreads/Bookly** — stack RN pur, monétisation prouvée, gaps précis. Candidat sérieux pour une app "quick win".
