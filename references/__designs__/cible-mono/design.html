07 — Do's & Don'ts

✓ Do

Use the display serif at 24px+ only — for screen titles and hero moments
Use the 4 pastel badge colors (peach, sage, amber, periwinkle) exclusively for task numbering
Keep backgrounds warm off-white (#FAFAF7) — never pure #FFFFFF as the page bg
Use circular shapes for all identity elements: avatars, badges, status dots
Let whitespace separate rows — no dividers or borders needed on task lists
Use forest green (#5B8A6F) as the one and only completion/success signal

✗ Don't

Never use neon, saturated, or vibrant colors — this system is deliberately desaturated
Never use a dark/black background for main screens — light-mode only
Never use teal (#5BB8C8) or blue (#4A90D9) outside the "official challenge" widget context
Never use the display serif at caption or body sizes — it loses all premium quality
Never add heavy drop shadows or visible card borders on list content
Never show more than 5 task rows without a "& More" collapse affordance
