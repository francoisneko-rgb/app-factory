7 — Do's and Don'ts
✓ Do
Keep screen backgrounds pure white on all task and tracking screens
Use the four pastel badge colors in fixed task-order sequence: amber → sage → peach → lemon
Use the script font (Caveat) only for emotional moment titles — "day N" markers
Keep task rows clean: badge + text + 1px divider, nothing else
Use full-radius pills only for challenge-selector chips, never for primary CTA buttons
Maintain the soft card shadow — it is the only depth signal in the system
✗ Don't
Never use dark backgrounds, gradients, or neon accent colors
Never saturate the pastel badges — they must stay muted and earthy
Never mix the script font with body text or labels
Never border-wrap each task row as a card — use thin dividers only
Never center-align task or list content — everything is left-aligned
Never add a fifth badge color — the system has exactly four task slots
