# ANALYSE — CLUSTERS MINEURS RESTANTS (2026-08-30)

## UTILITAIRES (compass, file manager, vpn, clean)
- **Revenus** : Documents (Readdle) ~$750K/mois (file manager), Moovit (transit) $530K.
- **Genre** : outils système (compass, fichiers, vpn, cleaner).
- **Stack RN** : RN + modules natifs. Complexité 3/5.
- ✅ Utilité réelle, gros volumes (Moovit, Documents).
- ⚠️ Apps gratuites par défaut (Apple), monétisation faible, fragmentation.
- **Verdict 5/10** : compliqué, peu monétisable sauf niche (vpn, file manager pro).
