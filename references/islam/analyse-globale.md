### Muslim Pro — ce qu'il fait exactement
- L'app islamique n°1 mondiale : **horaires de prière précis (géoloc), athan, qibla (AR), Quran
  complet (arabe + traductions + audio), du'as, 99 noms d'Allah, calendrier hégirien**.
- + **Qalbox** (contenu vidéo lifestyle), posts quotidiens, widgets. 22 langues. Sorti 2010,
  mis à jour 2026-08-29 (développement continu). Note 4.70.
- Monétisation : **freemium + abo premium ad-free** (Subs + IAPs + autre).

### Voix des utilisateurs — ce qui fait rêver
1. **"App must-have pour chaque musulman"** — utilisé en famille depuis 2015-2021 (loyauté extrême).
2. **Tout-en-un** : "I installed 30 different Islamic apps, this one does it all".
3. Quran avec traductions + athan + qibla dans UNE app = la valeur perçue.
4. **Daily posts / dua du jour** : engagement quotidien apprécié ("today posts", "neatly organized").
5. Confiance : des années de service fidèle.

### Voix des utilisateurs — plaintes (opportunités ÉNORMES)
1. **ADS massives si pas premium** : "so many ads I barely can use the app", "bombarded with
   Ads" — la plainte #1. Le freemium est perçu comme punitif.
2. **Modèle d'abonnement contesté moralement** : "forcing a muslim to pay monthly or be
   bombarded with ads = morally unethical" (2 avis 1★ sur ce thème) — risque de réputation.
3. **Widgets iOS cassés + Apple Watch** : "unable to make widgets on iPhone or a working app on
   Apple Watch" — un gap technique réel (récent).
4. **Notifications invasives** : "won't stop alerting me about Qalbox", pas d'option pour
   n'avoir QUE les prières.
5. **Pas de mode paysage iPad** (lecture du Quran difficile sur iPad Pro).
6. **Contraste du highlight de prière** illisible (vert opaque) + bug "full adhan" + contenu IA
   pas apprécié ("stop using AI content, hire artists").

### Synthèse monétisation
- **Abo premium ad-free** dominant + IAPs. $110K/mois sur 420K dl = **$0.26/download**.
- Le sentiment anti-abo est réel et documenté → une app qui respecte mieux (abo unique, pas
  d'ads agressives, lifetime dispo) peut capter les déçus.
- Marché multi-langues énorme (turc, arabe, français, indonésien, ourdou...) : 22 langues pour
  Muslim Pro mais chaque langue = opportunité ASO locale.

### Stack RN + difficulté
- **Stack RN** : RN + géoloc + calculs astronomiques (prières/qibla) + audio Quran + widgets iOS
  (WidgetKit via module natif). Complexité **2.5/5**.
- **Moat** : le contenu (Quran audio, traductions) + l'exactitude des horaires (multi-méthodes de
  calcul). Pas insurmontable : les données Quran sont open-source (API AlQuran, Tanzil...).

### Ce qu'il faudrait faire (sous-niche précise recommandée)
1. **App athan/prière "anti-avarice"** : horaires précis + qibla + rappels, SANS ads punitives,
   avec **lifetime purchase** (le souhait explicite des déçus de Muslim Pro) + widgets iOS
   impeccables + Apple Watch (les points faibles TECHNIQUES de Muslim Pro sont le gap).
2. **Azkar/du'as premium par langue** (le cluster islam-athkar existant) : contenu léger,
   RN simple, abo faible.
3. **Cibler UNE langue** : `namaz vakitleri` (turc, comp 29), `coran francais` (42/48) —
   Muslim Pro est fort partout mais une app 100% locale peut gagner la longue traîne locale.
4. **Éviter le dating musulman** (comp 20 mais complexité modération/confiance, et proximité
   culturelle délicate) sauf si l'utilisateur le valide explicitement.

### Verdict
- **Note : 7.5/10**. Demande massive et durable (420K dl/mois), monétisation prouvée ($110K/mois),
  stack RN simple.
- **Le gap #1 est clair** : les utilisateurs adorent le produit mais détestent le modèle
  (ads + abo). Une app avec widgets iOS qui marchent, pas d'ads punitives, et un prix lifetime
  a un argument différenciant documenté dans les avis.
- Risque : la confiance/religiosité du marché exige un produit irréprochable et respectueux ;
  les erreurs techniques (widgets, adhan) y sont très mal vécues.
