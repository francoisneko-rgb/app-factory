## Voix des utilisateurs (avis App Store, 10-11 avis riches)
**Ce qui fait rêver (5★)**
- **Le chien réagit** : "My dog… this whistler has a variety of pitches and she reacts to
  them", "my dog comes right to me".
- **Amusant / jeu** : "Y'all's game is so fun".

**Plaintes / frictions**
1. **Paywall** : "you have to pay for it. Like What That's Crazy" — le sifflet est payant
   (abo Dogo).
2. **Trop faible / pas assez fort** : "It's like quietest thing EVER", "Doesn't work",
   "I played the sound and my dog just laid down" — **efficacité variable** (attentes).
3. **Complexité d'usage** : "Not User Friendly", "It's not as simple as it makes it look",
   "I'm still trying to figure it out".
4. **Manque de conseils** : "doesn't give any helpful advice".
5. Pas de fréquence adaptée au chien expliquée clairement.

## Forces / Faiblesses
- **Forces** : fait partie de la suite **Dogo** (183K ratings, $140K/mois, 50K dl/mois) —
  le **vrai leader monétisé** de l'éducation canine ; sifflet + dressage + potty + tricks ;
  explication éducative des fréquences ; sentiment 95%.
- **Faiblesses** : sifflet payant (paywall frustrant), efficacité variable (certains chiens
  ne réagissent pas), usage pas toujours simple, manque de conseils intégrés pour débutants.

## Réutilisable pour nous
- **GAP / insight majeur** : le **dog whistle seul monétise très mal** (<$5K pour iTrainer),
  mais la **suite éducative complète** (Dogo = dressage + whistle + potty) encaisse
  **$140K/mois** sur 50K dl. **Leçon : le sifflet est une fonctionnalité d'appel, pas un
  produit fini monétisable.**
- **GAP (anti-Dogo)** : **sifflet gratuit/accessible** (anti-paywall frustrant), **guide de
  fréquence par race + conseils de dressage intégrés** (anti "no helpful advice"),
  **efficacité + volume réglable** (anti "quietest thing ever"), **simplicité d'usage**.
- Positionner le sifflet comme **porte d'entrée** d'une app d'éducation canine complète.
