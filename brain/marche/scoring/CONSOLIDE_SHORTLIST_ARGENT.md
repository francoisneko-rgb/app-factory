## DÉTAIL PAR NICHE

### 1. Challenges 75 jours (75 Hard / Soft) — ✅ TOP
- **Ce que c'est** : tracker de challenge 75 jours (checklists, streaks, eau, photos, calendrier).
- **Revenus concurrents (est. Appfigures)** : Her 75 = **$110K/mois** (120K dl) · Habit Tracker =
  **$120K/mois** (180K dl, modèle prix unique $8.99) · BeHard = **$65K/mois** · officiel 75 Hard =
  $15K/mois (RATÉ, sentiment 22%).
- **Concurrence** : l'app "officielle" est notée 2.5★ → la place est libre. Marché fragmenté, aucun géant.
- **Complexité** : 1-2/5 (listes, notifications, widget, stockage local). 4-6 semaines MVP.
- **Potentiel an 1** : $50-150K. Monétisation : prix unique ~$19.99 + abo optionnel (le lifetime convertit mieux).
- **Pourquoi on peut gagner** : demande réelle (pop 34-55 sur 4 mots-clés), leader détesté, preuve de revenus.
- ⚠️ « 75 Hard » est une marque déposée → faire un TRACKER personnalisable, pas l'app "officielle".

### 2. Mobility / souplesse — ✅ TOP
- **Ce que c'est** : routines d'étirements/mobilité articulaire + test de mobilité.
- **Revenus concurrents** : Bend = **$1M/mois** (340K dl, sentiment 100%) · GOWOD = **$380K/mois** (10K dl !) ·
  pliability = $40K/mois.
- **Concurrence** : modérée (58). Pas de monopole écrasant ; plaintes facturation sur GOWOD/pliability.
- **Complexité** : 2/5 (vidéos/illustrations + routines). 4-6 semaines MVP.
- **Potentiel an 1** : $50-150K. Abo annuel $24.99 (sous Bend, prix "honnête").
- **Pourquoi on peut gagner** : ARPU extrême (GOWOD fait $380K avec 10K dl → les gens paient cher pour ça).

### 3. Tai chi senior — ✅ TOP
- **Ce que c'est** : routines de tai chi guidées, douces, pour seniors (équilibre, prévention chutes).
- **Revenus concurrents** : Fast Builder (entrant de 11 mois !) = **$65K/mois** · 7 Minute Chi = <$5K (IAP unique =
  échec) · YUAN QI = <$5K.
- **Concurrence** : faible (comp 60-70). Le leader est un ENTRANT RÉCENT → la niche se prouve en croissance.
- **Complexité** : 2/5. Le travail = contenu (vidéos/animations des mouvements). 4-6 semaines.
- **Potentiel an 1** : $20-50K. Abo annuel $24.99 + **essai SANS carte bancaire** (différenciant seniors).
- **Pourquoi on peut gagner** : la leçon est nette — l'abonnement rapporte ($65K) là où l'achat unique échoue (<$5K).

### 4. Plant care (soins/rappels) — ✅ BON
- **Ce que c'est** : liste de plantes + rappels d'arrosage + journal photo (PAS l'identification IA, angle = soins).
- **Revenus concurrents** : Planta = **$480K/mois** · Blossom = $110K · Greg = $50K. Marché ≈ $640K/mois.
- **Concurrence** : modérée (70). Géants sur l'identification (PictureThis), l'angle soins est plus libre.
- **Complexité** : 2/5 (base de soins + algorithme de rappel + widget). 4-6 semaines.
- **Potentiel an 1** : $20-60K. Freemium généreux (rappel gratuit) + abo $24.99/an.
- **Pourquoi on peut gagner** : marché prouvé rémunérateur, angle soins peu disputé, plaintes précises (Greg verrouille le tracking).

### 5. Voice changer IA — ✅ BON
- **Ce que c'est** : changer sa voix (effets + génération IA de voix).
- **Revenus concurrents** : Voices AI = **$180K/mois** (360K dl) · Voicemod = $25K · One Pixel <$5K.
- **Concurrence** : modérée (60), aucun géant, beaucoup d'entrants IA récents.
- **Complexité** : 3/5 (audio temps réel + API IA). 6-8 semaines MVP.
- **Potentiel an 1** : $50-150K. Freemium + abo $4.99/mois (anti-Voices AI $30/mois jugé cher).
- **Risques** : coût API IA par génération, droits des voix célèbres (viser parodies/effets), défi technique iOS temps réel.
- **Pourquoi on peut gagner** : les gens paient pour l'IA ; free tier généreux + prix juste = différenciant.

### 6. Timers sport (intervalle/tabata) — ✅ BON (avec nuance)
- **Ce que c'est** : minuteur d'intervalles sportifs (HIIT, tabata, boxe).
- **Revenus concurrents** : Interval Timer = **$50K/mois** (40K dl) · timer boxe/mma <$5K (visiter le généraliste).
- **Concurrence** : faible (comp 42-61). Aucun géant.
- **Complexité** : 1/5 (la plus simple de toute la shortlist). Stack ultra-simple.
- **Potentiel an 1** : $30-100K. Prix unique (le scandale n°1 du segment = l'abonnement).
- **Nuance (ton intuition avait raison en partie)** : oui, "payer pour un timer" semble contre-intuitif, MAIS
  la donnée Appfigures prouve que les gens paient ($50K/mois pour Interval Timer, et $120K pour Habit Tracker
  en prix unique). Le créneau = "le timer honnête sans abonnement".

### 7. Escape room / puzzle — ⚠️ contenu lourd
- **Ce que c'est** : jeu de salles d'escape point-and-click 2D.
- **Revenus concurrents** : Rooms & Exits = **$250K/mois** · 50 Tiny Room = $15K · Room Escape 50 = $10K.
- **Concurrence** : basse (comp 51), devs indépendants, UI datée.
- **Complexité** : 3/5. Le vrai travail = CONTENU (20-50 salles × énigmes + art). 8-10 semaines.
- **Potentiel an 1** : $50-200K (mais c'est le plus long à produire en contenu).
- **Ton intuition est juste** : c'est plus compliqué/dur que les autres. Seul intérêt : grosse monétisation si le contenu suit.

### 8. Astrologie — ⚠️ géants sur le thème
- **Revenus concurrents** : Co-Star = **$650K/mois** (210K dl) · The Pattern = $560K · Astrotalk (IAP crédits, 4M dl).

## A. NOUVELLES DONNÉES COMBLÉES (les 2 angles morts du fichier)

### A1. Pickleball — l'angle mort est comblé, et change le verdict
Données publiques récoltées 2026-09-26 (site Pickleheads, sources presse/secteur) :
- **Pickleheads (le leader) est désormais un "petit géant"** : 745K+ utilisateurs, note 4.9 (10K ratings),
  partenariat Officiel USA Pickleball + DUPR intégré, **19 employés, seed financée $2.5M (2024)**.
- **La monétisation EXISTE et marche** (preuve que le marché paie) :
  - Players Plus : **$19.99/an** · Pro (organisateurs) : **$249.90/an** · Ultra (salles) : **$749.90/an**.
- **MAIS** : le moat du leader = **effet réseau** (les joueurs invités invitent leurs amis) + la
  data de 16K courts + partenariats officiels. C'est attackable sur les GROUPES LOCAUX (scheduler
  + round robin sans réseau), pas frontalement.
- **Verdict mis à jour** : la niche reste battable (comp 28 sur "playtime scheduler"), mais ce n'est
  plus "concurrence quasi nulle" : un leader sérieux, financé et en croissance est en place.
  Compatible "1ère app" seulement si on accepte de se nicher sur le local-first pur, sans
  construire de directory de courts (peut le faire ? oui), sinon PAS de PKL en app #1.
- **Classement : 4e.** L'argument "patience organisation de clubs" est real — mais risque plus élevé
  que les autres candidats (concurrence redevenue sérieuse).

### A2. Islam athkar — la donnée comblée montre une monetisation QUALITATIVE FAIBLE
Recherche web 2026-09-26 :
- **Muslim Pro** : est. **$13-85K/mois iOS** (AppCurrents, confiance FAIBLE) — énorme volume
  (598K ratings) mais un revenu comparable à des apps 10× plus petites.
- **Athan (IslamicFinder)** : 19M downloads cumulés, **60K downloads/mois Android**, 10M+
  Google Play, modèle = **pubs + abo ad-free** — le constat "pubs qui minent l'expérience" est
  confirmé (avis août 2026 : "the sheer number and intrusiveness of ads have made it a
  miserable experience").
- **Lecture** : la DEMANDE est massive, mais la MONÉTISATION par dollar est la plus faible du
  portefeuille : les bases d'utilisateurs sont en MENA/Asie du Sud (pouvoir d'achat faible),
  les acteurs sont ad-revenue-driven, pas abo-driven. Personne ne prouve qu'un athkar SANS PUB
  PAYÉ convertit bien pour l'instant.
- **Verdict** : excellent marché d'empêchement (les remplacer par une app propre = plait aux
  utilisateurs), mais **pas la preuve de revenus qu'on exige pour l'app #1**. Garder en réserve.
- **Classement : sans rang.**

## C. CE QUE CHOISIR — POURQUOI

### Pourquoi Challenges 75 jours est le meilleur choix d'APP #1
1. **Le plus "gagnable"** : le seul segment où le leader relaxant est l'APP "OFFICIELLE" de la
   tendance (75 Hard de 44SEVEN, note réelle 4.41, sentiment 0%, $15K/mois) — la place est
   laissée libre des deux côtés (marque ratée + petits plagias low-effort). Aucun géant type
   à l'horizon, aucun argus d'influence possible.
2. **Revenus prouvés sur PLUSEURS concurrents**, pas juste un : Her 75 $110K, Habit Tracker
   $120K (lifetime $8.99 = modèle anti-abonné plébiscité), BeHard $65K. → Le marché partage
   le gâteau entre 2-3 apps solides. Un nouveau venu bien fait peut prétendre $5-15K/mois
   ficelé (protocole connu : tracker fiable + widget + water tracker + lifetime $19.99).
3. **Stack la plus simple avec Timers** : listes + calendrier + streaks + notifications + widget
   iOS + HealthKit + photos locales. Aucun backend lourd (local + iCloud). Réaliste 4-6 semaines
   sur template `template-app/` → même pas besoin de module natif lourd. Aucune API à payer.
4. **Timing calendaire идеальный** : le pic de demande est JANVIER (nouvelles résolutions) +
   été. On peut construire maintenant et sortir AVANT la vague janvier.
5. **Aucun angle mort connu** : les plaintes (widget bugué, water tracker absent, données
   perdues, abo abuse) sont documentées dans 4 rapports d'avis + 2 sources Appfigures.
   Risque résiduel : "75 HARD" est une marque déposée → on fait un TRACKER personnalisable
   (pas le clone), comme BeHard le fait légalement depuis 2023.

### Pourquoi PAS les autres maintenant
- **Timers sport** : le candidat le plus simple (1/5), mais le segment ne montre qu'UN seul
  gagnant ($50K/mois) et aucun second ($<5K partout ailleurs). Si on n'attrape pas le
  généraliste directement, rien. Sa garde-fou : à faire comme app #2 (simple, rapide, PAS
  d'abonnement = lifetime $5-8, [watch/external display]), mais pas la priorité n°1 car
  plafond de marche plus bas.
- **Mobility** : super marché ($1M Bend) MAIS l'investissement initial est plus élevé (vidéos
  ou animations d'exercices de qualité = coût de contenu + vrai design + test de mobilité),
  et Bend est un acteur solide à $1M, pas un radeau. Parfait en app #2-3.
- **Tai chi senior** : presque parfait aussi (leader récent = marchée prouvée, seniors fidèles),
  MAIS demande modérée (33-37) et contenu animation tai chi = travail artistique non trivial.
  Excellent CO-vivant avec Mobility (même cible seniors, même stack) → à faire en version
  "routine douce" INCLUSE dans une app mobility-senior suivenieme, ou en app séparée plus tard.
- **Plant care** : très rémunérateur mais Planta/Blossom/Greg sont établis avec moat de contenu
  (base de soins); fenêtre "angle soins" existe mais demande un contenu de base conséquent.
  Bien comme app 3-4.
- **Voice changer** : le plus juteux des "à suivants" mais délicats financièrement (coût API)
  et techniquement (temps réel iOS). En dernier.
- **Escape room** : contenu lourd, best as app "longue respiration" quand on aura du budget
  contenu.
- **Pickleball / Islam / Astrologie** : gardées en réserve, raisons en A1/A2/sections 8-10.
